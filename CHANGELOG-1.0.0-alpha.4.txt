= 1.0.0-alpha.4 =

* Adds Multiple coupon support: several coupons can now be applied to one cart, combining a product specific coupon with a store wide one, with each coupon's share of the discount recorded per item
* Adds Wishlist for customer accounts, with save actions on the shop and product pages and a dedicated wishlist page
* Adds Address book: customers can save multiple addresses, label them, and choose a default for billing and shipping
* Adds Multiple address selection on the checkout page, kept in sync with the cart when an address changes
* Adds Multi currency settings with currency formatting and exchange rates entered manually or synced from a rate provider
* Adds Legal settings page for managing consent statements, with page link tokens and control over where each consent appears
* Adds Region based tax settings with per country strategies, a single rate option, VAT collection, and an inline tax rules editor
* Adds Per line tax records on orders, so orders with several tax rates keep each rate separate, and shipping tax is now stored on the order
* Adds Order tracking page for looking up an order by its reference
* Adds Invoice number to orders
* Adds Settings search across the settings panel, matching on both keywords and meaning, with highlighted results
* Adds Advanced settings page for page assignment, including a repair action for missing pages
* Adds Filters to the products, inventory, customers, coupons, and orders lists
* Adds Sorting, bulk actions, and column visibility controls to the data tables
* Adds Single variant editing from the product variants list
* Adds Rate limiting across the plugin, including a cooldown before a verification email can be resent
* Adds Unsaved changes bar so edits are not lost when navigating away
* Adds Default profile selection for tax and shipping profiles
* Adds Right to left language support to the storefront styles
* Adds Loading skeletons to every settings page
* Updates the admin interface to the new design system, covering form fields, dropdowns, media gallery, colors, badges, and page layouts
* Updates the order details screen with a redesigned summary, activity timeline, and payment status badge
* Updates the checkout order summary with a clearer price breakdown separating item discounts, order discounts, shipping, and tax
* Updates the storefront to use the native WordPress login and registration pages
* Updates the shipping zone list with a new design and an empty state
* Updates the terms and privacy consents, which moved from Checkout settings to the new Legal settings page
* Improves security with stricter input sanitization, output escaping, and secure redirects for WordPress.org compliance
* Fixes a money precision issue in amount calculations
* Fixes guest checkout failing when saving an address, and guest orders failing to save when edited
* Fixes coupon usage counts drifting out of sync when an order was edited or cancelled
* Fixes two tax rates that share a name, such as EU VAT at different percentages, collapsing into a single incorrect row
* Fixes order quantity limits not being applied when adding to cart
* Fixes variant details not showing when a variant is selected on a product
* Fixes state options not refreshing when the country is changed
* Fixes an error when adding a new currency
* Fixes theme style conflicts on storefront pages
* Fixes lag when opening the tax region dialog
* Fixes accidental quantity changes from mouse wheel scrolling
* Fixes broken product and fallback image URLs


--------------------------------------------------------------------------------
BREAKING CHANGES
--------------------------------------------------------------------------------

Coupons
  - orders.coupon_code and orders.discount_details dropped, replaced by the
    order_coupons relation.
  - carts.discount_details dropped, replaced by the cart_coupons join table.
  - coupon_usage table dropped; order_coupons takes over usage tracking with a
    denormalised customer_id. Cancelling an order now marks usage reversed
    instead of deleting the record.
  - Request field coupon_code replaced by coupon_codes (array) across order
    calculate, create and update requests.
  - CartResource / OrderResource replace discount_details with a coupons array.
  - remove_coupon now requires a coupon identifier.
  - Relations renamed: Order::coupons() -> Order::order_coupons(),
    OrderItem::coupons() -> OrderItem::order_item_coupons().
    Cart::coupons() keeps its name (returns Coupon[] via the pivot).

Tax
  - order_items.tax_rate and order_items.tax_breakdown (JSON) removed, replaced
    by the order_taxes table (one row per tax line, scoped to an order item or
    to shipping).
  - orders gains base_shipping_tax_amount / invoiced_shipping_tax_amount.

Cart pricing
  - CartResource (storefront) trimmed to money-object-only fields; the bare
    base_* / display_* duplicates were removed.
  - pricing.display_shipping_tax_money_object removed; shipping amount is now
    reported net of its own discount.

Addresses
  - PUT /account/addresses (update_addresses) removed. Use the
    /account/addresses CRUD endpoints instead.
  - postcode renamed to postal_code across all address payloads.
  - is_billing_same_as_shipping dropped from the orders and customers tables.
  - config.addresses must always be an array; the legacy single-address shape
    is no longer accepted.

Auth
  - Plugin-owned login and registration routes and pages removed; the site now
    uses native WordPress login and registration.

No backfill: existing carts and orders are not migrated into the new coupon or
tax tables. Alpha stage, no production data to preserve.
