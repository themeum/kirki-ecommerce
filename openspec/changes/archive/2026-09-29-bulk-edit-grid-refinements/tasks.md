- [x] 2.1 Reserve bottom clearance inside `#bulk-edit-scroll-container` (`bulk-edit-table.tsx`) so the native horizontal scrollbar no longer overlaps the last row's content. Implemented as `paddingBottom` on `styles.scrollContainer` — padding on an `overflow:auto` element is part of its scrollable area.
- [x] 2.2 Add right-side clearance inside the scrollable table content so the fill-handle grabber is never clipped on the right-most column, at any scroll position. **Correction**: `paddingRight` on `styles.scrollContainer` (the scrolling viewport) measured as still clipped by 3px when live-tested via Browser MCP — trailing/inline-end padding on a scroll container's own viewport is not reliably honored by browsers at the horizontal scroll boundary (unlike the bottom/block-end case in 2.1, which worked). Moved `paddingRight` onto `styles.table` (the actual scrollable content) instead, which is architecturally correct and verified clean via `getBoundingClientRect()` (grabber right edge 812 vs. container right edge 1001 — no clip).

- [x] 2.4 Shrink the Variants column's media thumbnail to 24×24px via a scoped `cssOverride` passed from `VariantIdentityControl` to `MediaPicker`, keeping the 32px cell height and the shared `media-picker.tsx` untouched.
